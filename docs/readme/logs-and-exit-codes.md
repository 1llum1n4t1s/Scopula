# 記録・終了コード・一時ファイル

- ログ: `<home>\logs\scopula-YYYY-MM-DD.log` に追記します。30日より古いログは、実行の最後に消します（`--dry-run` では消しません）。
- 終了コード: `0` 正常 / `1` 掃除後も警告の上限（既定 100GiB）を超える target がある / `2` 実行できなかった / `3` Prunlet の結果が不明で中断した。
- Everything の出力（`es-result.json`）と Prunlet の一時ファイルは `%TEMP%\scopula\<実行ID>` に作り、実行の最後に Prunlet で片付けます（`--dry-run` でもこの一時フォルダーだけは片付けます）。中断したときは片付けずに残し、次の正常な実行（dry-run 以外）で、24時間より古いものを片付けます。
- 表示するサイズは、ファイルの長さの合計です。ハードリンクされたファイルは複数の場所で数えるため、実際に空く量より多く見えることがあります。

## 戻せるか

削除は、ごみ箱が無効なボリュームにある target に限ります。判定の詳細は [README](../../README.md) の「戻せるか」を参照してください。結果は `recycled`・`permanently_deleted` などの状態ごとに集計し、ごみ箱が無効なのに `recycled` が返ったときは警告します。
